Blender API
============
All the scripts and modules tasked to read computational chemistry files in the formats
``.com``, ``.xyz``, ``.mol2``, or ``.vasp`` and convert them to ``.fbx``, ``.obj``, ``.dae``,
``.glb``, ``.stl``, or ``.usdz`` formats
